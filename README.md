# 厚德学校 · 香江路校区三维校园

可以旋转、缩放和点选的校园微缩场景，支持总览、俯视、正面与跑道视角。手机支持单指旋转、双指缩放。浏览器不支持三维显示时提供静态预览。

已按学校说明更新：

- 四栋教学楼前后分列：前排左右楼各5层，首层部分架空；后排副楼各7层，与中央尖顶高楼连接。
- 前后对应教学楼2—5层在内侧设开放连廊，带扶手与立柱，两排之间保留空地。
- 食堂住宿楼在左前篮球场旁、靠左侧马路，共6层，1—2层为食堂，上方为住宿区。
- 花园凉亭移至左后7层楼后，后侧半场篮球场移至右后7层楼后。
- 跑道加宽并延伸至最外侧，测量线周长保持250米，主席台位于靠教学楼一侧；四周道路把校园及跑道完整包在内部。

具体尺寸、楼名与部分比例仍可继续核对。

## 本地开发

需要Node.js 22或更新版本。

```bash
npm ci
npm run dev
npm test
npm run build
```

共享布局数据在 `public/campus.json`。网页为静态页面，不需要账号、数据库或API密钥。全部新增文字使用微软雅黑；只提供本页需要的字体子集。

## GitHub Pages

本仓库通过 `main` 分支的 `docs` 目录发布。更新后运行 `npm run build:pages`，检查页面，再提交源文件与 `docs`。

本站展示的是根据学校资料持续校正的校园模型，已补入学校说明的后方空间，部分不可见细节仍为简化表达。原始校园照片、本机来源路径、Blender工程和私有资料没有放入公开仓库。

技术依赖：Three.js、Vite，均按各自许可证使用。
